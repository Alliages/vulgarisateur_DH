# Versions
0.8.0 : première version, non fonctionnelle. Versions paires : gros changements ; impaires : corrections.

0.8.4 : retours des 24, 26 et 28 octobre 2026 (familles de fichiers, ordre des cartes, couleurs des fichiers dans Comparer, semaine superposée, dates en français, mode sans pyarrow). Toujours non fonctionnelle.

0.9.0 : version de test. Choix du fichier météo dans une fenêtre dédiée (recherche, familles, carte schématique des zones, fichiers en cartes avec chiffres clés, fichiers récents).

0.9.2 : version de test. Onglet Exporter (copier-coller des indicateurs, CSV et Excel, 1 ou 2 fichiers) ; haut de page fixe ; réglages repliés ; nouvel ordre des cartes ; graphique des nuits chaudes dans Comparer ; seul l'onglet ouvert est calculé (plus rapide) ; choix gardés dans le navigateur.

0.9.4 : version de test. Menu (bouton de repli toujours visible, carte du fichier entièrement cliquable), sources retirées sous les graphiques, nouveau pied de page avec le lien vers le code source, README réécrit.

0.9.5 : corrections. Tuiles de la fenêtre de choix cliquables sur toute leur surface, retour de la carte du fichier de la 0.9.2 dans le menu, nuits ≥ 20 °C sur le graphique de l'année, message Windows sans conséquence masqué dans la console.

0.9.7 : corrections. Graphique de l'année simplifié (nuits ≥ 20 °C en barres sous les DH, axe des DH jusqu'à 300 °C.h), « température fichier » à la place de « température extérieure ».

0.9.8 : version de test. Indicateurs rangés un par fichier (un nouvel indicateur s'ajoute sans toucher au reste de l'outil) ; import de fichiers plus sûr (dates jour/mois/année, messages d'erreur clairs, taille limitée) ; graphiques gardés en mémoire et démarrage plus rapide (pythermalcomfort n'est plus chargé) ; code réorganisé, sans changement des résultats.

0.9.9 : correction. Famille « Relevés » renommée « Observations » ; relevés de mai 2026 remplacés par les observations horaires Météo-France de 15 stations (au moins une par zone), du 1er mai au 30 septembre 2026.
